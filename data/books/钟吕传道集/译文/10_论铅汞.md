# 论铅汞第十·译文

> 吕曰："内药不出龙虎也。虎出于坎宫，气中之水是也。龙出于离宫，水中之气是也。外药取砂中之汞，比于阳龙。用铅中之银，比于阴虎。而铅汞外药也，何以龙虎交而变黄芽，黄芽就而分铅汞？所谓内药之中铅汞者，何也？"

吕洞宾发问：内药不离龙虎——虎出于坎宫（肾），是气中的真水；龙出于离宫（心），是水中的真气。外药取朱砂中的汞比喻阳龙，用黑铅中的银比喻阴虎。但铅汞本来是外药的概念，为什么前面说"龙虎交而变黄芽，黄芽就而分铅汞"？内药之中所说的"铅汞"到底指什么？

**解读**：吕祖的问题触及了内丹学中一个关键的名相转换——外丹术语如何内化为内丹概念。外丹烧炼中的铅和汞是实体的化学物质，但在内丹中，铅汞变成了人体精气神的象征。理解这个转换，才能真正读懂内丹经典。

> 钟曰："抱天一之质而为五金之首者，黑铅也。铅以生银，铅乃银之母。感太阳之气而为众石之首者，朱砂也。砂以生汞，汞乃砂之子。难取者铅中之银、砂中之汞。银汞若相合，锻炼自成至宝。此铅汞之理见于外者如此。"

钟离权先从外丹的角度解释铅汞：

- **黑铅**：抱"天一"之质，为五金之首（"天一"出自河图，天一生水，铅色黑属水）。铅能生银，铅是银之母。
- **朱砂**：感太阳之气，为众石之首。朱砂能生汞，汞是砂之子。
- **关键点**：难取的是铅中的银和砂中的汞（不是粗铅和粗砂，而是其中的精华）。银和汞若相合，锻炼自成至宝。

**解读**：外丹语境中，铅和汞的关系是"母子"关系——铅生银（如母生子），砂生汞（如母生子）。但丹家追求的不是铅和砂本身，而是其中的精华：铅中之银、砂中之汞。将这两味精华相合锻炼，才是至宝（金丹）。

> 钟曰："若以内事言之，见于人者，古今议论，差别有殊，取其玄妙之说。本自父母交通之际，精血相合，包藏真气，寄质于母之纯阴之宫，藏神在阴阳未判之内。三百日胎完，五千日气足。以五行言之，人身本是精与血，先有水也。以五脏言之，精血为形象，先生肾也。肾水之中，伏藏受胎之初父母之真气，真气隐于人之内肾，所谓铅者，此也。肾中生气，气中真一之水名曰真虎，所谓铅中银者，此也。肾气传肝气，肝气传心气，心气太极而生液，液中有正阳之气。所谓朱砂者，心液也。汞者，心液中正阳之气。积气液为胎胞，传送在黄庭之内。进火无差，胎仙自化，乃此铅银合汞，锻炼成宝者也。"

钟离权转述内丹层面的铅汞含义——从人的生命起源说起：

**生命的起点**：
- 父母交媾之际，精血相合，其中包藏着真气。
- 这真气寄存在母亲的子宫（纯阴之宫）中，藏神于阴阳未判分的混沌状态。
- 三百日胎成，五千日（约十四年）气足——人身发育完成。

**铅的对应**：
- 按五行，人身本质是精和血，最先有的是"水"。
- 按五脏，先生成的是肾。
- 肾水中伏藏着受胎之初的父母真气，这真气隐藏在人的内肾之中——这就是内丹所说的**"铅"**。

**铅中银的对应**：
- 肾中生出气，气中的真一之水就是"真虎"——这就是内丹的**"铅中银"**（铅的精华）。

**朱砂和汞的对应**：
- 肾气传给肝气，肝气传给心气，心气太极运转而生液。
- 液中的正阳之气就是"汞"的本源。
- **朱砂**对应心液，**汞**对应心液中的正阳之气。

**最终成果**：
- 将气液积聚为胎胞，运送到黄庭（中丹田）之内。
- 进火不出差错，胎仙自然化生——这就是铅中银与汞相合、锻炼成宝的内丹过程。

**解读**：这是本章最核心的段落。钟离权建立了完整的铅汞内景对应关系：

| 外丹概念 | 内丹对应 | 来源 |
|---------|---------|------|
| 黑铅 | 父母真气（藏于肾） | 先天 |
| 铅中银 | 肾气中的真一之水（真虎） | 肾中生气 |
| 朱砂 | 心液 | 心气生液 |
| 砂中汞 | 心液中的正阳之气 | 液中正阳 |
| 铅银合汞 | 真一之水合正阳之气 | 龙虎交媾→黄芽→金丹 |

需要注意，"五千日气足"这个数字——五千日约等于13.7年，大致对应青春期发育完成的年龄（男子二八十六岁精气溢泄）。这意味着人体在青春期之后先天真气开始向外耗散，也是修道者应该开始"逆修"的起点。

> 吕曰："在五金之中，铅中取银。于八石之内，砂中出汞。置之鼎器，配之药饵，汞自为砂而银自为宝。然而在人之铅，如何取银？在人之砂，如何取汞？汞如何作砂？银如何作宝也？"

吕洞宾追问具体操作：在外丹中，可以从铅中取出银、从砂中炼出汞，放入鼎器配制药饵，汞自然会变为丹砂、银自然会成为至宝。但在人体之中，这个"铅中取银""砂中取汞""汞变为砂""银变为宝"的过程怎么实现？

**解读**：吕祖问的是操作层面的问题——方法论。理论懂了，怎么下手？

> 钟曰："铅本父母之真气合而为一，纯粹而不离。既成形之后而藏在肾中。二肾相对，同升于气，乃曰元阳之气。气中有水，乃曰真一之水。水随气升，气住水住，气散水散。其水与气，如子母之不相离。善视者，止见于气不见于水。若以此真一之水，合于心之正阳之气，乃曰龙虎交媾而变黄芽，以黄芽为大药，大药之材，本以真一之水为胎，内包正阳之气，如昔日父母之真气，即精血为胞胎。造化三百日，胎完气足而形备神来，与母分离。形外既合，合则形生形矣。奉道之人，肾气交心气，气中藏真一之水负载正阳之气，以气交水为胞胎，状同黍米，温养无亏。始即阴留阳，次以用阳炼阴。气变为精，精变为汞，汞变为砂，砂变为金丹。金丹既就，真气自生，炼气成神而得超脱。化火龙而出昏衢，骖玄鹤而入蓬岛。"

钟离权详述内丹中铅汞的转化过程：

**铅的本质**：
铅是父母真气合而为一，纯粹不分离。成形之后藏在肾中。两肾相对，同升于气，这就是元阳之气。气中有水，即是真一之水。水随气而升，气停水就停，气散水就散。水与气如母子般不分离。善于观察的人只能看到气，看不到水——因为水藏于气中。

**铅中取银——龙虎交媾**：
将真一之水（铅中银）与心之正阳之气（砂中汞）相合，这就是龙虎交媾，变成黄芽。黄芽就是大药的材料。大药以真一之水为胎，内包正阳之气——就像当初父母真气以精血为胞胎一样。

**汞变为砂、银变为宝——内丹的孕育过程**：
- 修道者将肾气交心气，气中藏着真一之水负载正阳之气。
- 以气交水为胞胎，状如黍米（极小的一点）。
- 温养不亏——先是"阴留阳"（阴包阳），然后用"阳炼阴"。
- 转化链条：气 → 精 → 汞 → 砂 → 金丹。
- 金丹成就 → 真气自生 → 炼气成神 → 超脱。
- 最终："化火龙而出昏衢"（乘火龙出离昏暗的尘世），"骖玄鹤而入蓬岛"（驾玄鹤进入蓬莱仙岛）。

**解读**：这一段将人体内丹的孕育过程与母体孕育胎儿做了完整的类比：

| 母体生育 | 内丹修炼 |
|---------|---------|
| 父母真气（精血） | 真一之水（铅中银）+ 正阳之气（砂中汞） |
| 胞胎 | 黍米大小的"丹胎" |
| 三百日胎成 | 三百日丹成（黄芽→金丹） |
| 婴儿出母体 | 阳神脱凡胎（"化火龙""骖玄鹤"） |

"骖玄鹤"——骖（cān），指驾车时在两旁的马，这里作动词，意为驾驭。玄鹤是仙人的坐骑。这个意象象征阳神脱离肉体后自由遨游仙境的状态。

"昏衢"（hūn qú）——昏暗的道路，比喻轮回生死的迷途。

> 吕曰："以形交形，形合生形。以气合气，气合生气，数不出三百日。分形之后，男女形状之不同，自己丹砂色泽之何似也？"

吕洞宾问一个很具体的问题：男女交合（形交形）生出孩子需要三百日，但生出的男女不同。那么内丹修炼（气合气）三百日后，自己的"丹砂"是什么颜色、什么样子？

**解读**：吕祖用男女交合生儿育女来类比内丹的气合生气，问了一个直白的问题——炼丹成功后，那个"金丹"到底是什么样子的？

> 钟曰："父母之形交，父精先进而母血后行，血包于精而为女。女者，中阳而外阴，以象母，盖以血在外也。若以母血先进而父精后行，精包于血而为男。男者，内阴而外阳，以象父，盖以精在外也。所谓血者，本生于心而无正阳之气。所谓精者，本生于肾而有正阳之气。正阳之气乃汞之本也，即真一之水和合而入黄庭之中，汞用铅汤煮，铅以汞火煎。铅不得汞，不能发举真一之水。汞不得铅，不能变化纯阳之气。"

钟离权先解释男女形成的原理，再以此推出内丹的炼制机制：

**男女形成的奥秘**：
- 女：父精先进，母血后行 → 血包精 → 生女（内阳外阴，像母亲，因为血在外）。
- 男：母血先进，父精后行 → 精包血 → 生男（内阴外阳，像父亲，因为精在外）。
- 血生于心，没有正阳之气（故女为阴体）。
- 精生于肾，含有正阳之气（故男为阳体）。
- 正阳之气就是汞的根源。

**内丹的铅汞互炼**：
- 真一之水和合进入黄庭（中丹田）。
- "汞用铅汤煮，铅以汞火煎"——汞需要铅的汤液来烹煮，铅需要汞的火力来煎炼。
- 铅不得汞 → 不能发动真一之水上升。
- 汞不得铅 → 不能将正阳之气变化为纯阳。

**解读**：这一段表面上在讲男女胎孕的生理学，实际上是用来说明铅汞相须的道理。"铅不得汞，不能发举真一之水"——真一之水（铅中银）虽然藏在肾中，但没有汞（心中正阳之气）的火力催动，它就是死水一潭，无法上升。"汞不得铅，不能变化纯阳之气"——正阳之气（汞）虽有炎上的本性，但没有真一之水（铅）的制约和滋养，它就会耗散而无法凝结为纯阳金丹。

"汞用铅汤煮，铅以汞火煎"——这是极精妙的修炼口诀。铅汤是水（真一之水），汞火是火（正阳之气），水火相交、铅汞互炼，才能结成金丹。

> 吕曰："铅在肾中而生元阳之气，气中有真一之水，视之不可见也。铅以得汞，汞生正阳之气。以正阳之气烧炼于铅，铅生气盛，而发举于真一之水，可以上升。然而汞本正阳之气，即真一之水，而为胞胎，保送在黄庭之中，是龙虎交媾，阴阳两停，亦以铅汤煮之，莫不阴太过，耗散真阳，安得成大药而气中生气也？"

吕洞宾追问一个火候平衡的问题：铅在肾中生元阳之气，气中有真一之水（看不见）。铅得汞之后，汞的正阳之气来烧炼铅，铅气充盛，真一之水就可以上升。但汞的正阳之气和真一之水结合成胞胎，保送到黄庭中，这就是龙虎交媾、阴阳平衡。这时还要用"铅汤"来煮——难道不会阴气太过而耗散真阳吗？怎么才能结成大药、做到"气中生气"？

**解读**：吕祖的问题很关键——如果在龙虎交媾（阴阳平衡）之后再加入铅（阴），那不就变成阴盛阳衰了吗？这个问题的核心在于对"铅汤"的理解。

> 钟曰："肾气投心气，气极生液。液中有正阳之气，配合真一之水，名曰龙虎交媾。每日得之黍米之大，名曰金丹大药，保送黄庭之中。且黄庭者，脾胃之下，膀胱之上，心之北而肾之南，肝之西而肺之东，上清下浊，外应四色，量容二升，路通八水。所得之药，昼夜在其中。若以采药不进火，药必耗散而不能住。若以进火不采药，阴中阳不能住，止于发举肾气而壮暖下元而已。若以采药有时而进火有数，必先于铅中作，借气进火，使大药坚固，永镇下田，名曰采补之法。而炼汞补丹田，延年而益寿，可谓地仙。若以采药而以元铅抽之，于肘后飞金晶。既抽铅，须添汞。不添汞，徒以还精补脑，而真气如何得生？真气不生，阳神如何得就也？添汞须抽铅，不抽铅，徒以炼汞补丹田，如何变砂？砂既不变，而金丹如何得就？"

钟离权层层解析采药进火的法则：

**黄庭的位置**：
脾胃之下、膀胱之上，心之北、肾之南，肝之西、肺之东——即身体的正中央。上清下浊（上半身清、下半身浊），外应四色（青赤白黑四象），容积约二升，道路通向八水（全身津液通道）。所得之药（黄芽）昼夜存放在这里。

**三个层次的操作**：

1. **只采药不进火**（基础错误）：药必然耗散，留不住。
2. **只进火不采药**（另一个错误）：阴中之阳无法稳固，只能"发举肾气、壮暖下元"而已——这只是养生，不是炼丹。
3. **采药有时、进火有数**（正确方法）：必须在"铅"中下手——借气进火，使大药坚固，永镇下田。这个方法叫"采补之法"，可以炼汞补丹田、延年益寿，做到地仙。

**更高层次——抽添**：
如果以采药配合"元铅"来抽之（即抽铅添汞），从肘后飞金晶（督脉上升），进入更高的修炼层次：
- 既抽铅，必须添汞——如果不添汞，只是"还精补脑"而没有真气新生，阳神如何成就？
- 添汞必须抽铅——如果不抽铅，只是"炼汞补丹田"而无法变化为丹砂，金丹如何成就？

**解读**：这一段将修炼分为明显的高低层次：
- 养生阶段：进火壮暖下元（基础）
- 采补之法：采药进火、永镇下田（中等，成地仙）
- 抽添之道：抽铅添汞、肘后飞金晶（高等，成神仙）

"还精补脑"是一个很容易被误解的概念。它不等于简单的"憋精不放"，而是指将肾中真气（精的本质）通过督脉上升补益大脑——这是一个能量转化的过程，而非生理层面的操作。

本段末引出了下一章（第十一章"论抽添"）的主题。钟离权在这里做了巧妙的过渡：采药进火是基础，但要真正成就阳神，必须在采药的基础上进一步抽铅添汞。

---

**本章要点总结**：
1. 内丹中的铅汞是外丹术语的内化——铅指肾中父母真气，汞指心中正阳之气。
2. 铅中银 = 肾气中的真一之水（真虎），砂中汞 = 心液中的正阳之气（真龙）。
3. 铅汞互炼：铅不得汞不能上升，汞不得铅不能凝为纯阳——两者相须为用。
4. 修炼三层次：养生（壮暖下元）→ 采补（炼汞补丹田，成地仙）→ 抽添（抽铅添汞，成神仙）。
5. 黄庭是体内炼丹的"鼎器"，位于五脏之正中。
6. 铅汞修炼最终模拟的是父母孕育胎儿的生命创造过程。
