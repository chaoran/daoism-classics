# 论河车第十二·译文

> 吕曰："所谓河车者，何也？"

吕洞宾问：所谓的"河车"到底是什么？

> 钟曰："昔有智人，观浮云蔽日可以取荫而作盖。观落叶浮波，可以载物而作舟。观飘蓬随风往来运转而不已，退而作车。且车之为物，盖轸有天地之象，转毂如日月之比。高道之士，取喻于车，且车行于地而转于陆。今于河车，亦有说矣。盖人身之中，阳少阴多，言水之处甚众。车则取意于搬运，河乃主象于多阴，故此河车，不行于地而行于水。自上而下，或前或后，驾载于八琼之内，驱驰于四海之中。升天，则上入昆仑。既济，则下奔凤阙。运载元阳，直入于离宫；搬负真气，曲归于寿府。往来九州，而无暂停；巡历三山，而无休息。龙虎既交，令黄婆驾入黄庭；铅汞才分，委金男搬入金阙。玉泉千派，运时止半刻工夫；金液一壶，搬过只片刻功迹。五行非此车搬运，难得生成一气。非此车搬运也，岂能交会？应节顺时而下功，必假此车而搬之，方能有验。养阳炼阴之事，必假此车搬之，始得无差。乾坤未纯，或往来其阴阳，是此车之功也。宇宙未周，或交通其血气，是此车之功也。自外而内，运天地纯粹之气，而接引本宫之元阳。自凡而圣，运阴阳真正之气，而补炼本身之元神，其功不可以备纪。"

钟离权先阐述"河车"这一名称的来源和意义：

**命名的由来**：
古代智者观察自然现象来发明器物——看浮云遮日可以取荫而制作伞盖；看落叶浮水可以载物而造舟船；看飘蓬随风往来运转不停，退而制作车轮。而"车"这个东西，车盖和轸木（车厢底部横木）有天地之象（上圆下方），车轮转动如同日月运行。

修道高人借"车"来比喻——车在陆地上行驶。但"河车"不同：因为人身之中阳少阴多，说"水"的地方极多（参考第七章的四海五湖九江等）。"车"取搬运之意，"河"象征多阴之水。所以河车不是行于陆地，而是行于水中。

**河车的运行范围**：
- 自上而下、或前或后，驾行于"八琼"（身体各处精微所在）之内，驰骋于"四海"（血海、气海、髓海、水谷之海）之中。
- 上升则入"昆仑"（头顶百会）。
- 既济（水火相交完成后）则下奔"凤阙"（下丹田）。
- 运载元阳直入离宫（心），搬负真气曲归寿府（肾）。
- 往来"九州"（全身各部分）无暂停，巡历"三山"（三丹田）无休息。

**河车在不同修炼环节的作用**：
- 龙虎交媾后 → 令黄婆（真意）驾入黄庭（中丹田）。
- 铅汞才分开 → 委金男（比喻阳气）搬入金阙（上丹田）。
- 玉泉千派（津液运行），用河车运转只需半刻工夫。
- 金液一壶（金液还丹），搬过只需片刻。
- 五行之气，没有河车搬运就不能生成一气。
- 没有河车搬运，气液也无法交会。
- 按时节下功修炼，必须借助河车搬运才有验证。
- 养阳炼阴，必须借助河车搬运才没有差错。
- 乾坤未纯（阴阳不纯），往来运转阴阳——河车的功劳。
- 宇宙未周（全身气机不周遍），交通血气——河车的功劳。
- 自外而内，运天地纯粹之气接引本宫元阳。
- 自凡而圣，运阴阳真正之气补炼本身元神。

河车的功效不可尽数！

**解读**：钟离权用大量篇幅铺陈河车的重要性，实际上是在为这个核心修炼工具树立崇高地位。"八琼""九州""三山"等术语都是用地理概念比喻人体内部空间。

"黄婆"再次出现——在龙虎交媾中，黄婆（真意/意念）是媒合龙虎的关键力量；在河车运转中，黄婆则是驾驭河车的"车夫"。这说明意念在整个内丹修炼中始终起着核心的引导作用。

"金男"是继"黄婆"之后的又一个拟人化概念，指阳气（金，西方白虎之象），负责将铅汞分开后的精华搬运到上丹田。

> 吕曰："河车如此之妙用，敢问河车之理。毕竟人身之中，何物而为之？既得之，而如何运用？"

吕洞宾追问实质性问题：河车究竟是什么东西？怎么运用它？

> 钟曰："河车者，起于北方正水之中，肾藏真气，真气之所生之正气，乃曰河车。河车作用，今古罕闻，真仙秘而不说者也。如乾再索于坤而生坎，坎本水也，水为阴之精。阳既索于阴，阳返负阴而还位，所过者艮、震、巽。以阳索阴，因阴取阴，搬运入离，承阳而生，是此河车搬阴入于阳宫。及夫坤再索于乾而生离，离本火也，火乃阳之精。阴既索于阳，阴返抱阳而还位，所过者坤、兑、乾，以阴索阳，因阴取阳，搬运入坎，承阴而生。是此河车运阳入于阴宫。及夫采药于九宫之上，得之而下入黄庭。抽铅于曲江之下，搬之而上升内院。玉液、金液本还丹，搬运可以炼形，而使水上行。君火、民火本炼形，搬运可以烧丹，而使火下进。五气朝元，搬运各有时。三花聚顶，搬运各有日。神聚多魔，搬运真火以焚身，则三尸绝迹。药就海枯，搬运霞浆而沐浴，而入水无波。此河车之作用也。"

钟离权解释河车的本质和运行机制：

**河车的本质**：
河车起于"北方正水"之中——即肾。肾中藏着真气，真气产生的"正气"就是河车。这个作用今古罕闻，是仙真秘而不宣的东西。

**解读**：这里给出了河车的本质定义——河车不是解剖学上的某个器官，而是肾中真气所生发出的一种搬运功能。"北方正水"出自河图（天一生水，北方属水），对应肾。

**河车的两条搬运路线**：

**路线一：搬阴入阳宫**
- 乾再索于坤 → 生坎（坎卦，中间一阳被两阴包裹）。
- 坎本为水，水是阴之精。阳（中间那一阳）索于阴，阳返回时背负着阴而还位。
- 所经过的卦位：艮、震、巽（对应督脉路线上的关卡）。
- "以阳索阴，因阴取阴"——用阳来牵引阴，借阴来采取阴。
- 搬运入离（心/离宫），承受阳气而生长。
- 这就是河车**搬阴入于阳宫**。

**路线二：运阳入于阴宫**
- 坤再索于乾 → 生离（离卦，中间一阴被两阳包裹）。
- 离本为火，火是阳之精。阴（中间那一阴）索于阳，阴返回时抱着阳而还位。
- 所经过的卦位：坤、兑、乾（对应任脉路线）。
- "以阴索阳，因阴取阳"——用阴来牵引阳，借阴来采取阳。
- 搬运入坎（肾/坎宫），承受阴气而生长。
- 这就是河车**运阳入于阴宫**。

**解读**：这里用八卦理论来解释河车的运转路线。坎（水，肾）和离（火，心）是核心，"索"字出自《说卦传》"乾天也，故称乎父；坤地也，故称乎母。震一索而得男……坎再索而得男……离再索而得女"。钟离权将八卦生成理论与人体内气运行结合，构建了河车的理论模型。

两条路线实际上对应着：
- **督脉上升**（搬阴入阳宫）：真气从肾出发→经艮震巽（尾闾、夹脊、玉枕三关）→到达离宫（心/脑）。
- **任脉下降**（运阳入阴宫）：津液从心出发→经坤兑乾（重楼等）→回到坎宫（肾/下丹田）。

这就是后来所说的"小周天"循环。

**河车的各种应用**：
- 采药于九宫之上→下入黄庭。
- 抽铅于曲江之下→上升内院（肘后飞金晶）。
- 玉液金液还丹→搬运炼形→使水（津液）上行。
- 君火民火炼形→搬运烧丹→使火下行。
- 五气朝元→搬运各有时节。
- 三花聚顶→搬运各有日期。
- 神聚多魔→搬运真火焚身→三尸绝迹。
- 药就海枯→搬运霞浆沐浴→入水无波（寒暑不侵）。

**解读**："九宫"指上丹田（头部泥丸九宫）。"曲江"指下丹田，因肾水如江河弯曲而名。"抽铅于曲江之下，搬之而上升内院"——这就是第十一章讨论的"肘后飞金晶、还精补脑"。

"神聚多魔"说明修炼到一定阶段，精神高度集中时会遇到各种幻觉魔障，需要用真火来"焚身"以清除。"三尸"再次出现——河车运转真火可以彻底消灭三尸神。

> 吕曰："河车本北方之正气，运转无穷。而负载阴阳，各有成就，所用功不一也，尊师当为细说。"

吕洞宾请钟离权详细说明河车的不同层次。

> 钟曰："五行循环，周而复始，默契颠倒之术，以龙虎相交而变黄芽者，小河车也。肘后飞金晶，还晶入泥丸，抽铅添汞而成大药者，大河车也。以龙虎交而变黄芽，铅汞交而成大药。真气生而五气朝中元，阳神就而三神超内院。紫金丹成，常如玄鹤对飞；白玉汞就，正似火龙涌起。而金光万道，罩俗骨以光辉；琪树一株，现鲜葩而灿烂。或出或入，出入自如，或去或来，往来无碍。搬神入体，且混时流，化圣离俗，以为羽客。乃曰紫河车也。是此三车之名，而分上、中、下三成。故曰三成者，言其功之验证，非比夫释教之三乘，而曰羊车、鹿车、大牛车也。"

钟离权将河车分为三个层次：

**一、小河车**
- **操作**：五行循环，周而复始，默契颠倒之术。
- **成果**：龙虎相交 → 变黄芽。
- **层次**：下成（初级成就）。

**解读**：小河车是基础层次，对应的就是五行颠倒、龙虎交媾、产生黄芽的阶段。这是内丹修炼的入门功夫。

**二、大河车**
- **操作**：肘后飞金晶，还晶入泥丸（上丹田），抽铅添汞。
- **成果**：成就大药。
- **层次**：中成（中级成就）。

**解读**：大河车是在小河车基础上的进阶——黄芽已经产生，现在要通过督脉把精华搬运到泥丸、再通过任脉下降，完成"抽铅添汞"的小周天循环，将黄芽炼化为大药。

**三、紫河车**
- **前提**：先完成龙虎交变黄芽（小河车），再完成铅汞交成大药（大河车）。
- **成果**：真气生→五气朝中元（五脏气朝归中丹田），阳神就→三神超内院（精气神三宝升华）。
- **内景描述**：
  - "紫金丹成，常如玄鹤对飞"——金丹紫光，如一对玄鹤翱翔。
  - "白玉汞就，正似火龙涌起"——纯白汞成，如火龙涌起。
  - "金光万道，罩俗骨以光辉"——万道金光笼罩凡身。
  - "琪树一株，现鲜葩而灿烂"——一株玉树绽放绚烂之花。
- **能力**：出入自如、往来无碍。搬神入体可以混在世俗人群中，化圣离俗则为仙人（羽客）。
- **层次**：上成（最高成就）。

**解读**："紫河车"是三种河车中的最高层次，也是最神秘的概念。为什么叫"紫河车"？"紫"是最高贵的颜色（紫微星、紫金丹），"河车"是搬运的工具。"紫河车"与医学上"紫河车"（胎盘）名称相同并非巧合——胎盘是孕育生命的原始载体，紫河车则是在修炼者体内孕育"圣胎"的终极载体。

"三神"指精气神凝聚的最高形态——元婴/阳神。"琪树"（qí shù）是仙境的玉树，这里比喻体内真气凝结的景象。

**与佛教三乘的区别**：
钟离权特别指出：三成（小河车、大河车、紫河车）说的是功夫的验证层次，不同于佛教的三乘（羊车、鹿车、大牛车/大白牛车）。佛教三乘出自《法华经·譬喻品》的火宅喻——羊车喻声闻乘、鹿车喻缘觉乘、牛车喻菩萨乘。钟离权特意区分，说明道教内丹的"三车"是独立的理论体系。

> 钟曰："以道言之，河车之后更有三车：凡聚火而心行意使，以攻疾病，而曰使者车。凡既济自上而下，阴阳正合，水火共处，静中闻雷霆之声，而曰雷车。若心为境役，物以情牵，感物而散于真阳之气，自外而内，不知休息，久而气弱体虚，以成衰老矣。或而入邪五疫，返以搬入真气，元阳难为抵挡，既老且病而死者，曰破车。"

钟离权补充三种特殊的"车"：

**一、使者车**
- **现象**：聚火于心，以心意驱使，用来攻击疾病。
- **性质**：治疗性的河车运用。

**二、雷车**
- **现象**：水火既济、阴阳正合之际，在静定中听到雷霆之声。
- **性质**：修炼深入时出现的体内能量爆破现象。

**三、破车**
- **现象**：心被外境奴役、情被物欲牵引，感于外物而消散真阳之气。从外到内不断损耗，不知休止，久而气弱体虚，走向衰老。或者被邪气五疫侵入，反而搬运了病气入体，元阳难以抵挡——既老且病而死。
- **性质**：这是常人（不修炼者）的"逆向搬运"——河车照样在运转，但搬的不是真气而是病气邪气，最终走向衰亡。

**解读**：使者车、雷车、破车三者，分别代表了河车原理的三种特殊表现。特别是"破车"的概念极为深刻——常人虽然没有主动修炼，但身体内部的"搬运"功能仍在运行，只是方向反了：不是搬运真气升华为阳神，而是搬运外邪消耗元阳，最终走向死亡。这呼应了"顺则成人，逆则成仙"的基本原理。

"静中闻雷霆之声"——这是修炼者在深度静定中常见的体验。当体内气机积聚到一定强度时，会突然爆发突破关卡，伴随类似雷鸣的声音，这是正常的内景现象。

> 吕曰："五行颠倒而龙虎相交，则小河车已行矣。三田返复而肘后飞金晶，则大河车将行矣。然而紫河车何日得而行焉？"

吕洞宾问：小河车、大河车的条件都清楚了，紫河车什么时候才能运行？

> 钟曰："修真之士，既闻大道，得遇明师，晓达天地升降之理，日月往来之数。始也匹配阴阳，次则聚散水火。然后采药进火，添汞抽铅，则小河车当行矣。及夫肘后飞金晶入顶，黄庭大药渐成，一撞三关，直超内院，后起前收，上补下炼，则大河车固当行矣。及夫金液、玉液还丹，而后炼形，炼形而后炼气，炼气而后炼神，炼神合道，方曰道成。以出凡入仙，乃曰紫河车也。"

钟离权总结完整的修炼次第：

**小河车阶段**：
修真之士听闻大道、得遇明师，精通天地升降之理和日月运行之数。
1. 匹配阴阳
2. 聚散水火
3. 采药进火
4. 添汞抽铅
→ 小河车当行。

**大河车阶段**：
1. 肘后飞金晶入顶（泥丸）
2. 黄庭大药渐渐成就
3. 一撞三关（尾闾、夹脊、玉枕）
4. 直超内院（上丹田）
5. 后起前收（督升任降完成周天循环）
6. 上补下炼（上补元神、下炼形质）
→ 大河车当行。

**紫河车阶段**：
1. 金液、玉液还丹
2. 炼形
3. 炼气
4. 炼神
5. 炼神合道 → 道成
6. 出凡入仙
→ 紫河车当行。

**解读**：这是对全书前面各章的一个系统性总结。整个修炼次第可以概括为：

小河车（基础）→大河车（核心）→紫河车（终极）

对应的功法层次：
匹配阴阳 → 聚散水火 → 采药进火 → 添汞抽铅 → 龙虎交媾（小河车）
→ 肘后飞金晶 → 黄庭成大药 → 一撞三关 → 周天循环（大河车）
→ 金液玉液还丹 → 炼形炼气炼神 → 炼神合道 → 出凡入仙（紫河车）

"炼形而后炼气，炼气而后炼神，炼神合道"——这是道教内丹修炼的终极路线图，也是《钟吕传道集》后面章节（第十三章起）将要展开论述的内容。

1. 河车是体内真气运行的搬运系统，起于肾中真气，本质上是一种"正气"的运转功能。
2. 河车有两条基本路线：督脉上升（搬阴入阳宫）和任脉下降（运阳入阴宫），构成小周天循环。
3. 河车分三个层次：
   - **小河车**（下成）：龙虎交媾变黄芽
   - **大河车**（中成）：肘后飞金晶、抽铅添汞成大药
   - **紫河车**（上成）：炼形炼气炼神、炼神合道、出凡入仙
4. 另有三种特殊之车：使者车（治病）、雷车（静中闻雷声）、破车（常人损耗元阳走向死亡）。
5. 整个修炼次第从匹配阴阳开始，到炼神合道结束，环环相扣，不可躐等。
