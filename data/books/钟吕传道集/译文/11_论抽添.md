# 论抽添第十一·译文

> 吕曰："采药必赖气中之水，进火须借铅中之气，到底抽铅成大药。若以添汞，上可以补丹田。所谓抽添之理，何也？"

吕洞宾发问：采药必须依赖气中的真水，进火必须借助铅中的元气，归根结底要"抽铅"才能成就大药。而"添汞"则可以向上补益丹田。这个抽添的道理究竟是什么？

**解读**：吕祖在上章末尾听到"抽铅添汞"的概念后，在本章正式追问其原理。抽添是内丹修炼中最精细的火候操作，是区分"养生"和"修仙"的关键技术。

> 钟曰："昔者上圣传道于人间，以太古之民淳而复朴，冥然不知，不可得闻大道。天地指喻阴阳升降之宜，交换于温、凉、寒、暑之气，而节候有期。一年数定，周而复始，不失于道，天地所以长久。不虑人之不知而阐于大理，蔽在一隅。比说于日、月精华往来之理，进退在旦望弦朔之时，而出没无差。一月数足，运行不已，不失于道，日月所以长久。奈何寒往暑来，暑往寒来，世人不悟天地升降之宜，月圆复缺，月缺复圆，世人不悟日月往来之理，恣纵无穷之意，消磨有限之时。富贵奢华，算来装点浮生之梦，恩爱悉烦，到底做下来生之债。歌声未绝而苦恼早来，名利正浓而红颜已去。贪财贪货，将谓万劫长存。爱子怜孙，显望永世同聚，贪痴不息，妄想长生，而耗散元阳，走失真气。直待恶病缠身，方是歇心之日。大限临头，才为了手之时。真仙上圣，悯其如此轮回，已而仍归堕落，深欲世人明悟大道，比于天地、日月之长久。"

钟离权先从大道理说起：

上古圣人传道于人间，因为太古之民淳朴无知，无法直接听闻大道。于是用天地阴阳升降的节候来比喻——春夏秋冬、寒暑温凉，年年如此，从不出错，天地因此长久。又用日月精华的进退来比喻——初一十五、朔望弦晦，月月如此，运行不息，日月因此长久。

**但是世人呢？**
- 寒来暑往、月圆月缺这样的天地大道明摆在眼前，世人却视而不见。
- 放纵无穷的欲望，消磨有限的寿命。
- 富贵奢华？不过是装点一场浮生之梦。
- 恩爱烦恼？说到底只是做下了来生的冤债。
- 歌声还没停，苦恼就来了；名利正浓时，红颜已经老去。
- 贪财贪货，以为万劫长存；爱子怜孙，盼望永世同聚。
- 贪痴不息却妄想长生——只能耗散元阳、走失真气。
- 直到恶病缠身，才肯歇心；大限临头，才知放手。

仙真上圣怜悯世人如此轮回堕落，深切希望世人明白大道，效法天地日月的长久。

**解读**：这一段是钟离权对世间迷恋红尘之人的深刻劝诫。"浮生之梦""来生之债"的比喻极为精辟。"歌声未绝而苦恼早来，名利正浓而红颜已去"——这是对人生无常的千古感叹，与《红楼梦》"好了歌"异曲同工。

> 钟曰："始也备说天地、阴阳升降之理，次以比喻日月精华往来之理。彼以不达天机，罔测玄妙。以内药比外药，以无情说有情。无情者，金石。金石者，外药也。有情者，气液。气液者，内药也。大之天地，明之日月，外之金石，内之气液。既采须添，既添须抽。抽添之理，乃造化之本也。"

钟离权给出抽添的宇宙论基础：

圣人先用天地阴阳升降讲道理，再用日月精华往来作比喻。世人不懂得天机玄妙，圣人只好以内药比喻外药、以无情说明有情：

- **无情**：金石（外药）
- **有情**：气液（内药）

大到天地，明到日月，外到金石，内到气液——"既采须添，既添须抽"，抽添的道理是造化万物的根本。

> 钟曰："且冬至之后，阳升于地，地抽其阴。太阴抽而为厥阴，少阳添为阳明。厥阴抽而为少阴，阳明添而为太阳。不然，无寒而变温温而变热者也。夏至之后，阴降于天，天抽其阳。太阳抽而为阳明，少阴添而为厥阴。阳明抽而为少阳，厥阴添而为太阴。不然，无热而变凉，凉而变寒也。是以天地阴阳升降而变六气，其抽添之验也。"

**天地的抽添**：

**冬至之后（阳气回升）**：
- 阳从地中升起，地面抽取阴气。
- 太阴 → 抽为厥阴（阴减一档），少阳 → 添为阳明（阳增一档）。
- 厥阴 → 再抽为少阴（阴又减一档），阳明 → 再添为太阳（阳达到最盛）。
- 这就是从寒变成温、温变成热的过程。

**夏至之后（阴气回升）**：
- 阴从天而降，天抽取阳气。
- 太阳 → 抽为阳明（阳减一档），少阴 → 添为厥阴（阴增一档）。
- 阳明 → 再抽为少阳（阳又减一档），厥阴 → 再添为太阴（阴达到最盛）。
- 这就是从热变成凉、凉变成寒的过程。

天地通过阴阳升降变化出六气（风寒暑湿燥火），这就是抽添的验证。

**解读**：钟离权将"抽添"提升到宇宙根本法则的高度。这里使用了中医六气/六经的概念——太阳、阳明、少阳、太阴、少阴、厥阴——来说明阴阳转换中"抽"和"添"的具体过程。"抽"就是减少一方的力量，"添"就是增加另一方的力量，阴阳就是通过这一抽一添完成从量变到质变的转化。

> 钟曰："若以月受日魂，日变月魄，前十五日，月抽其魄而日添其魂，精华已满，光照上下。不然，无初生而变上弦，上弦而变月望者也。若以月还阴魄，日收阳精，后十五日，日抽其魂而月添其魄，光照已谢，阴魄已足。不然，无月望而变下弦，下弦而变晦朔者也。是此日月往复而变九六，其抽添之验也。"

**日月的抽添**：

前十五日（月亮由缺变圆）：
- 月亮抽取自身的魄（阴），太阳添加魂（阳）。
- 精华满盈，光照上下——从初生（新月）→ 上弦 → 月望（满月）。

后十五日（月亮由圆变缺）：
- 太阳抽取自己的魂（阳），月亮添加魄（阴）。
- 光辉收敛，阴魄充足——从月望 → 下弦 → 晦朔（月末月初的暗月）。

日月往复变化出"九六"之数（九为老阳、六为老阴），这也是抽添的验证。

**解读**：以月相变化说抽添，更加直观。月亮本身不发光，其光辉来自太阳的照射（"月受日魂"）。前半月月亮反射面增大（"日添其魂"），后半月减小（"月添其魄"）。一添一抽之间，完成了阴阳的周期性转化。这与《周易参同契》中用月相纳甲说炼丹火候一脉相承。

> 钟曰："世人不达天机，罔测玄理。真仙上圣以人心所爱者无病长生，将金石炼大丹。以人心所好者，黄金白银，将铅汞成至宝。本欲世人悟其大理。无情之金石，火候无差，抽添有数，尚可延年益寿。若以己身有情之正阳之气，真一之水，知交合之时，明采取之法，积日累月，气中有气，炼气成神，以得超脱，莫不为古今难得之事。人间天上少得解悟，当以志心行持而弃绝外事，效天地日月长久，诱劝迷途，留心于道，故有外药之说。今古圣贤，或而陈说，得闻于世。世人又且不悟，欺己罔人，以失先师之本意。将砂取汞，以汞点铅，即铅干汞。用汞变铜。不顾身命，狂求财货。互相推举，以好道为名，其实好利，而志在黄白之术。先圣上仙不得已而随缘设化，对物教人而有铅汞之说，比喻于内事。且铅汞自出金石，金石无情之物，尚有造化而成宝。若以有情自己所出之物，如铅汞之作用，莫不亦有造化，既有造化，莫不胜彼黄白之物也。奉道之士，当以深究之而勿执在外丹与丹灶之术。"

钟离权做了一段总结性的论述：

圣仙本意是用金石外丹来启发世人明白大道——连无情的金石，只要火候不差、抽添有数，尚能延年益寿。那么用自己身体中有情的正阳之气和真一之水，知道交合的时机、明白采取的方法，日积月累做到"气中有气、炼气成神"，超脱生死，岂不更是理所当然？

然而世人总是不悟，欺己骗人，曲解先师本意：
- 把砂中取汞、汞点铅变成"黄白之术"（炼金术骗局）。
- 不顾身命，狂求财货。
- 互相吹捧，以好道为名，其实好利。

仙圣们不得已，只好随缘设化，用铅汞来比喻内修。铅汞出自金石，金石无情都能造化成宝；身体有情的物质，岂不更有造化、远远胜过那些黄白之物？

**修道者应当深究内丹之理，不要执着于外丹和丹灶之术。**

**解读**：钟离权在此对"黄白术"（炼金术）做了严厉批判。历史上的确有许多人以炼丹为名行骗，将丹道降格为造金术。钟离权将内丹和外丹、真修和骗术做了清晰切割，强调"有情之物"（自身精气神）远胜"无情之金石"。

> 钟曰："且夫人之铅也，乃天地之始，因太始而有太质，为万物之母。因太质而有太素。其体也，为水中之金；其用也，为火中之水。五行之祖而大道之本也。既以采药为添汞，添汞须抽铅，所以抽添非在外也。自下田入上田，名曰肘后飞金晶，又曰起河车而走龙虎，又曰还精补脑而长生不死。铅既后抽，汞自中降，以中田还下田。始以龙虎交媾而变黄芽，是五行颠倒，此以抽铅添汞而养胎仙，是三田返复。五行不颠倒，龙虎不交媾。三田不返复，胎仙不气足。抽铅添汞，一百日药力全，一百日圣胎坚，三百日胎仙完而真气生。真气既生，炼气成神。功满忘形而胎仙自化，乃曰神仙。"

钟离权论述内丹中"抽添"的具体操作：

**铅的本体论地位**：
人之铅是天地之始——由太始而有太质（有形之物），太质为万物之母；由太质而有太素（气的精纯状态）。铅的体性是"水中之金"（坎中一阳），铅的作用是"火中之水"（离中一阴）。铅是五行之祖、大道之本。

**抽添的操作路径**：
- 采药就是添汞，添汞必须抽铅——抽添不在外物，都在自己身体中。
- 从下田入上田（下丹田→上丹田）：这叫**"肘后飞金晶"**，也叫**"起河车而走龙虎"**，也叫**"还精补脑而长生不死"**。
- 铅抽到上田之后，汞自然从中下降，由中田还归下田。

**抽添的两个阶段**：
1. **五行颠倒**（龙虎交媾变黄芽）——这是抽添的基础。
2. **三田返复**（抽铅添汞养胎仙）——这是抽添的深化。
   - 五行不颠倒 → 龙虎不交媾（不会产生黄芽）
   - 三田不返复 → 胎仙气不足（不会孕育阳神）

**修炼日程**：
- 抽铅添汞100日 → 药力全
- 再过100日 → 圣胎坚固
- 再过300日 → 胎仙完满、真气产生
- 真气产生 → 炼气成神 → 功满忘形 → 胎仙自化 → 成为神仙

**解读**：这一段将抽添的过程和成果说得非常清楚。"肘后飞金晶"是最重要的内丹术语之一——肘后指背部（督脉路线），金晶即铅（肾中真气）。其路线是：真气从下丹田出发→沿督脉上升→通过尾闾、夹脊、玉枕三关→进入泥丸（上丹田）。这一过程又叫"还精补脑"。"三田返复"指真气在上、中、下三丹田之间循环运转。

"五行颠倒"和"三田返复"是对前几个章节概念的整合——龙虎交媾（第七章讲水火、第八章讲龙虎）需要五行颠倒才能实现；抽铅添汞（本章）需要三田返复才能完成。

> 吕曰："出于金石者：外铅、外汞，抽添可以为宝。出于己肾中所藏父母之真气而为铅，真一、正阳所合之药变而为汞。抽添可以生神。所谓真铅，真汞亦有抽添乎？"

吕洞宾问：外铅外汞经过抽添可以成宝，身内的真铅真汞经过抽添可以生神——那真铅和真汞之间也有抽添吗？

> 钟曰："始也得汞须用铅，用铅终是错。故以抽之而入上宫，元气不传，还精入脑，日得之汞，阴尽阳纯。精变为砂，而砂变为金，乃曰真铅。真铅者自身之真气合而得之也。真铅生真气之中、气中真一之水。五气朝元而三阳聚顶。昔者金精下入丹田，升之炼形而体骨金色。此者真铅升之内府而作出白光。自下而上，自上而下，还丹炼形，皆金精往复之功也。自前而后，自后而前，焚身合气，皆真气造化之功也。若以不抽不添，止于日用，采药进火安有如此之功验？"

钟离权给出更高层次的回答：

**关键口诀**："始也得汞须用铅，用铅终是错。"——开始时得汞需要借助铅的力量，但一直依赖铅终究是错的。所以要把铅抽入上宫（上丹田），元气不外传，还精入脑。这样每天得到的汞，阴尽阳纯，精变为砂，砂变为金——这才是**真铅**。

**真铅的定义**：真铅是"自身之真气"相合而成。真铅生于真气之中、气中的真一之水。

**修炼的验证**：
- "五气朝元"——五脏之气朝归上丹田。
- "三阳聚顶"——三阳之气汇聚于头顶。
- 金精（真铅）下入丹田，升之炼形 → 体骨呈现金色（内视中的景象）。
- 真铅升入内府 → 发出白光。
- 自下而上、自上而下 → 还丹炼形，都是金精往复的功效。
- 自前而后、自后而前 → 焚身合气，都是真气造化的功效。

如果不用抽添，只停留在日常的采药进火，怎么会有这样的功效？

**解读**："始也得汞须用铅，用铅终是错"——这是本章最精警的一句话。它的意思是：修炼初期需要以铅（肾中真气）为根基来获得汞（心中真液），这是必经阶段；但如果一直依赖铅而不懂得转化升华，那就是错误的。所以必须"抽铅入上宫"，把铅从下丹田抽到上丹田进行还精补脑的转化。

"金精"是一个重要概念，指真铅升华后的精华物质。金精在下丹田和上丹田之间往复，产生"体骨金色""内府白光"等内景，这些都是修炼有成的内证体验，非臆想可得。

> 吕曰："凡抽之添之，如何得上下有度，前后无差？"

吕洞宾问关键的操作问题：抽添要怎么做到上下有分寸、前后不差错？

> 钟曰："可升之时不可降，可抽之时不可添，上下往来，无差毫厘，河车之力也。"

钟离权答：该升的时候不能降，该抽的时候不能添。上下往来分毫不差——这靠的是"河车"的力量。

**解读**：最后一句引出了下一章的主题——河车。"河车"是体内真气运行的动力系统，是实现抽添的技术工具。该升时升、该降时降、该抽时抽、该添时添，这一切精准的节度控制，都要依赖河车的运转。第十二章就是专门论述河车的。

---

**本章要点总结**：
1. 抽添是宇宙的根本法则——天地的寒暑变化、日月的盈亏圆缺，都是抽添的体现。
2. 外丹的兴起本来是为了教化世人明白抽添之理（无情金石尚可成宝，何况有情之身），但被世人曲解为"黄白术"骗术。
3. 内丹的抽添路线：下田→上田（肘后飞金晶，即还精补脑）→中田→下田（三田返复）。
4. 修炼两个阶段：先"五行颠倒"（龙虎交媾变黄芽），再"三田返复"（抽铅添汞养胎仙）。
5. "始也得汞须用铅，用铅终是错"——初期借铅得汞是必要的，但必须通过抽添将铅升华。
6. 抽添的火候节度必须借助"河车"之力——引出下一章主题。
