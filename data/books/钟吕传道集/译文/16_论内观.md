# 论内观第十六 · 译文

---

> 吕曰："所谓内观之理，可得闻乎？"

> 钟曰："内观、坐忘、存想之法，先贤后圣有取者、有不取者。虑其心猿意马，无所停留。恐因物而丧志，而无中立象。使耳不闻而目不见，心不狂而意不乱。存想事物，而内观坐忘，不可无矣。奈何少学无知之徒，不知交会之时，又不晓行持之法，但望存想而成功。意内成丹，想中取药。鼻抽口咽，望有形之日月，无为之天地，留止腹中，可谓儿戏。所以达士奇人，于坐忘存想一旦毁之，乃曰梦里得财，安能济用？画地为饼，岂可充饥？空中又空，如镜花水月，终难成事。然而有可取者。盖易动者片心，难伏者一意。好日良时，可采可取也。虽知清净之地，奈何心为事役，志以情移。时比电光，寸阴可惜，毫末有差，而天地悬隔、积年累月而不见功，其失在心乱而意狂也。善视者，志在丹青之美，而不见泰华。善听者，志在丝竹真音，而不闻雷霆。耳目之用小矣，尚以如此，况一心之纵横六合，而无不赅，得时用法之际，能不以存想内观而致之乎？"

**解读：** 这一章是《钟吕传道集》最富有辩证意味的一章。钟离权一开篇就发出了看似矛盾的论断：有些圣贤推崇内观存想，有些则彻底否定。

### 内观存想的争议

**反对者的理由**：一些无知之辈，不懂龙虎交媾的时机，不知行持的方法，妄想仅凭"存想"就能成功。他们在意念中想象成丹、想象取药，用鼻子吸气、口中吞咽，把"有形的日月"和"无为的天地"想象留存在腹中——这简直是儿戏。

所以有见识的人彻底否定存想之法，说：
- "梦里得财，安能济用？"——梦中发财，能当钱用吗？
- "画地为饼，岂可充饥？"——画饼能充饥吗？
- "镜花水月，终难成事"——镜中花、水中月，终究是虚幻的

**支持者的理由**：但内观存想也不能完全否定。原因在于：
- **心易动**：人的心念极为活跃，难以安定
- **意难伏**：意念需要聚焦，随心散乱则一事无成
- **时如电光**：修炼的时机稍纵即逝，分毫之差就是天地之别
- **心乱意狂**：修炼多年不见效，根本原因是心念散乱

钟离权举例说：善于看画的人，专心于丹青之美，连泰山华山都看不见；善于听音乐的人，专心于丝竹之音，连雷霆都听不到。耳目这种小器官都能如此专注，"况一心之纵横六合"——心念的力量可以贯通天地六合，在修炼的关键时刻，怎么能不依靠存想内观来收摄心神呢？

**核心观点**：存想内观的目的不在于"创造实相"，而在于**收摄心神、专注一念**。它不是最终目的，而是达到目的的手段。

**钟离权的辩证态度**：内观存想如同渡河之舟——到了彼岸就应该放下，但在渡河过程中不可或缺。"未得鱼则筌不可失矣，未获兔则蹄不可无矣"——没有捕到鱼时不能丢掉渔具，没有捉到兔子时不能丢掉猎网。下文将会阐明这个立场。

## 一、阳升阴降的存想对应

> 吕曰："所谓存想、内观，大略如何？"

> 钟曰："如阳升也，多想为男、为龙、为火、为天、为云、为鹤、为日、为马、为烟、为霞、为车、为驾、为花、为气。若此之类，皆内观存想，如是以应阳升之象也。如阴降也，多想为女、为虎、为水、为地、为雨、为龟、为月、为牛、为泉、为泥、为船、为叶。若此之类，皆内观存想，如是以应阴降之象也。青龙、白虎、朱雀、玄武，既有此名，须有此象。五岳、九州、四海、三岛、金男、玉女、河车、重楼，呼名比类，不可具述，皆以无中立象以定神识。"

**解读：** 这里给出了内观存想的具体操作指南。钟离权将存想的意象分为"阳升"和"阴降"两大类：

### 阳升之象

| 意象 | 象征 |
|------|------|
| 男 | 阳性的力量 |
| 龙 | 阳刚的活力 |
| 火 | 上升的热量 |
| 天 | 至高至纯 |
| 云 | 轻盈上升 |
| 鹤 | 仙逸飞升 |
| 日 | 光明温暖 |
| 马 | 奔腾向上 |
| 烟 | 袅袅上升 |
| 霞 | 灿烂光辉 |
| 车 | 向上搬运 |
| 驾 | 驾驭引导 |
| 花 | 开放向外 |
| 气 | 无形上升 |

### 阴降之象

| 意象 | 象征 |
|------|------|
| 女 | 阴柔的力量 |
| 虎 | 下沉的威猛 |
| 水 | 向下流动 |
| 地 | 厚重承载 |
| 雨 | 从天而降 |
| 龟 | 沉静内敛 |
| 月 | 清冷幽静 |
| 牛 | 沉稳负重 |
| 泉 | 涌出下流 |
| 泥 | 沉淀凝聚 |
| 船 | 浮载下降 |
| 叶 | 飘落归根 |

**关键原理**："既有此名，须有此象"——道教修炼中的青龙、白虎、朱雀、玄武、五岳、九州、河车、重楼等术语，每一个都有对应的内在意象。修炼者要在心中建立清晰的图像，以"无中立象"来安定神识。

"无中立象"这四个字极为重要——在虚无的意识中建立起具体的形象，以此来引导气的运行方向。这并非自欺欺人，而是利用心念的力量来调动身体的能量。

## 二、存想的辩证态度

> 钟曰："未得鱼则筌不可失矣，未获兔则蹄不可无矣。后车将动，必履前车之迹。大器已成，必为后器之模。则内观之法行持不可缺矣。亦不可执之于悠久，绝之于斯须，皆不可也。若以绝念无想，是为真念，真念是为真空。真空一境，乃朝真迁化而出昏衢，超脱之渐也。开基创始，指日进功，则存想可用。况当为道日损，以入希夷之域，法自减省，全在向观者矣。"

**解读：** 这是钟离权对内观存想最精辟的总结。

### 工具论

- "未得鱼则筌不可失矣"——没捕到鱼时，渔具不可丢弃
- "未获兔则蹄不可无矣"——没捉到兔子时，猎网不可缺少
- "后车将动，必履前车之迹"——后来的车要开动，必须顺着前车的轨迹

存想内观是修炼的**工具**而非目标。在修炼的初期和中期，"指日进功，存想可用"；当修行到了一定境界后，"法自减省"——方法自然简化，存想也随之放下。

### 两种极端都要避免

- **"执之于悠久"**——永远执着于存想，不肯放下，这是错误
- **"绝之于斯须"**——完全废弃存想，一刻不用，这也是错误

### 从有念到无念

最终的境界是："绝念无想，是为真念，真念是为真空"——当所有的刻意存想都放下后，留下的才是真正的"念"，这个真念就是"真空"。真空的境界是朝向真境、脱离昏昧迷途的开始，也就是"超脱之渐"。

**通俗理解**：存想如同学骑车的辅助轮——初学时必不可少，但当真正学会了，辅助轮就要卸掉。如果永远不卸，就无法真正骑车；如果一开始就卸掉，就永远学不会。这正是钟离权的辩证智慧。

## 三、各种修炼阶段的存想方法

### （一）坎离相交、匹配阴阳之想

> 吕曰："若以龙虎交媾而匹配阴阳，其想也何似？"

> 钟曰："初以交合配阴阳而定坎离，其想也，九皇真人引一朱衣小儿上升，九皇真母引一皂衣小女下降，相见于黄屋之前。有一黄衣老妪接引，如人间夫妇之礼，尽时欢悦。女子下降，儿子上升，如人间分离之事。既毕，黄妪抱一物，形若朱橘，下抛入黄屋，以金器盛留。然此男者，是乾索于坤，其阳复还本位，以阳负阴而还本乡。是此女者，是坤索于乾，其阴复还本位，以阴抱阳而会本乡。是曰坎离相交，而匹配阴阳之想也。"

**解读：** 这是"坎离相交"阶段的具体存想法。

**场景设定**：
- **九皇真人**：引朱衣小儿（阳、离火）上升
- **九皇真母**：引皂衣小女（阴、坎水）下降
- **黄屋**：中丹田（黄庭）
- **黄衣老妪**：脾土之神（媒介）

**过程**：
1. 朱衣小儿（阳）与皂衣小女（阴）在黄屋前相见，如同人间夫妇之礼
2. 交合欢悦后分离：女子下降，儿子上升
3. 黄妪抱出一物，形如朱橘（金丹的雏形），抛入黄屋，以金器盛放

**易理对应**：
- "朱衣小儿上升" = 乾索于坤（阳从阴中取回），阳复还本位
- "皂衣小女下降" = 坤索于乾（阴从阳中取回），阴复还本位

这就是"坎离相交"的内在意象——修炼者通过这样的存想来引导心肾之气的交媾。

---

### （二）龙虎交媾变黄芽之想

> 钟曰："若以炎炎火中，见一黑虎而上升。滔滔浪里见一赤龙而下降。二兽相逢，交战在楼阁之前。朱门大启，烰烰烟焰之中，有王者指顾。大火焚天，而上有万丈波涛，火起复落，烟焰满于天地。龙虎一盘一绕，而入一金器之中。下入黄屋之间，似置在笼柜之中。若此龙虎交媾而变黄芽之想也。"

**解读：** 这是"龙虎交媾"产生黄芽的存想法。

**场景**：
- **炎炎火中**（心中）：一只黑虎（肾水之精）上升
- **滔滔浪里**（肾中）：一条赤龙（心火之神）下降
- **二兽相逢**于楼阁前交战
- **朱门大启**：烟焰中有一王者（元神）指挥
- **大火焚天**，上有万丈波涛：水火既济的宏大意象
- **龙虎盘绕**：最终进入金器之中，降入黄屋（中丹田），如同放入笼柜之中

**象征意义**：黑虎为坎中真阳（肾精），赤龙为离中真阴（心神）。龙虎交媾不是简单的"心肾相交"，而是其中精华的融合。龙虎盘绕进入金器，象征着产生了最初的"丹基"——黄芽。

---

### （三）进火烧炼丹药之想

> 吕曰："匹配阴阳、龙虎交媾、内观、存想既已知之矣，所谓进火烧炼丹药者，所想如何？"

> 钟曰："其想也，一器如鼎如釜，或黄或黑。形如车轮，左青龙而右白虎，前朱雀而后玄武。傍有二臣，衣紫袍，躬身执圭而立。次有仆吏之类，执薪燃火于器。次有一朱衣王者，乘赤马，驾火云，自空而来，举鞭指呼，唯恐火小焰微。炎炎亘空，撞天欲出。天关不开，烟焰复下，周围四匝。人物、器釜、王者、大臣，尽在红焰之中，互相指呼，争要进火。器中之水，无气而似凝结。水中之珠，无暗而似光彩。若此进火烧丹药之想也。"

**解读：** 这是"进火烧炼"阶段的存想方法，场景极为生动。

**场景设定**：
- **中心**：一鼎器，或黄或黑，形如车轮
- **四方护法**：左青龙、右白虎、前朱雀、后玄武
- **两臣**：紫袍躬身执圭（辅助者）
- **仆吏**：执薪燃火
- **朱衣王者**：乘赤马、驾火云而来，举鞭指挥，唯恐火烧得不够旺盛

**火焰景象**：
- "炎炎亘空，撞天欲出"——火焰烧到极处，几乎要冲破天际
- "天关不开，烟焰复下"——天关未开，火焰倒流，四周皆是烈焰
- 人、物、器、王、大臣全在红焰之中
- 器中之水"无气而似凝结"（真液在火中不沸腾）
- 水中之珠"无暗而似光彩"（金丹在液中发光）

**关键理解**："水中之珠"就是丹药的本体。火焰虽猛烈，水却不沸腾，珠在火中生光——这是水火既济、阴阳平衡的内在意象。修炼者通过这样的存想来引导体内真火的烧炼，"进火"不是实际的加热，而是意领气行、以火炼金的功夫。

### （四）各阶段的存想总览

> 吕曰："内观存想，止于采药进火而有耶？逐法逐事而有耶？"

> 钟曰："云雷下降，烟焰上起。或而天雨奇花，祥风瑞气起于殿庭之下。或而仙娥玉女，乘彩凤祥鸾自青霄而来金盘中，捧玉露霞浆，而下献于王者，若此乃金液还丹而既济之想也。"

**解读：** 这是**金液还丹/既济**阶段的存想：祥云瑞气、天降奇花、仙娥玉女献玉露霞浆——象征内丹成就、水火既济后的圆满景象。

---

> "若龙虎曳车于火中，上冲三关，三关各有兵吏，不计几何。器仗戈甲，恐惧于人。先以龙虎撞之不开，次以大火烧之方启，以至昆仑不住，及到天池方止。或而三鹤冲三天，或而双蝶入三宫，或而五彩云中，捧朱衣小儿而过天门。或而金车玉辂，载王者而超三界。若此，肘后飞金晶，大河车之想也。"

**解读：** 这是**肘后飞金晶/大河车**阶段的存想：

龙虎拉车在火中上冲三关（尾闾、夹脊、玉枕），每一关都有兵吏把守，需用龙虎撞击、大火烧灼才能打开。冲过三关后到达昆仑（头顶）不停，直到"天池"（上丹田）才止。

其他意象：三鹤冲三天、双蝶入三宫、朱衣小儿过天门、金车玉辇载王者超三界——都象征着真气沿督脉上升、冲破关卡的过程。

**说明**："大河车"是比"小河车"（五脏间运行）更大的周天搬运。此节的"三关兵吏"意象生动地描述了通关的艰难——每一关都需要强大的能量突破。

---

> "及夫朱衣使者乘车循行，自冀州入兖州，自兖州入青州……东、西、南、北，毕于豫州停留，而后循行。……或而游五岳，自恒山为始。或而泛五湖，自北沼为始。……若此还丹之想也。"

**解读：** 这是**还丹**阶段的存想：以九州、五岳、五湖为意象，朱衣使者（元气）乘车巡回于九州之间，代表真气在全身各部位的周流循环。

---

> "及夫珠玉散掷于地，或而雨露济泽于物，或而海潮泛满百川，或而阴生以发万汇，或而火发以通天地，或而烟雾以充宇宙。若此炼形之想也。"

**解读：** 这是**炼形**阶段的存想：珠玉散地（真气布满全身）、雨露济物（玉液润泽）、海潮满川（气血充盈）、火发通天地（阳气流布）——象征着炼形时真气浸润四肢百骸的过程。

---

> "及夫或如鹤之辞巢，或如龙之出穴，或如五帝朝天，或如五色云起，或如跨丹凤而冲碧落，或如梦寐中而上天衢，或如天花乱坠，仙乐嘈杂，金光缭绕以入宫殿繁花入处，若此皆朝元之想也。朝元之后，不复存想，方号内观。"

**解读：** 这是**朝元**阶段的存想：鹤辞巢、龙出穴、五帝朝天、五色云起、跨凤冲碧落、天衢上天、天花乱坠、仙乐金光——所有意象都指向"向上、归位、朝见"的主题。

**关键的一句**："朝元之后，不复存想，方号内观"——在朝元完成之后，不再需要任何存想，此时才真正进入"内观"的本体境界。内观不是存想，而是超越了存想的纯然观照。

## 四、真正的内观

> 吕曰："内视玄理，不比前法，可得闻乎？"

> 钟曰："古今修道之士不达天机，始也不解，依法行持，欲以速求超脱，多入少出而为胎息，冥心闭目以行内观。止于定中以出阴神，乃作清灵之鬼，非为纯阳之仙。……殊不知内观之法，乃阴阳变换之法，仙凡改易之时。奉道之士，如得轻示而小用之矣。且以前项之事，交会有时日，行持有法则，凡能道节信心，依时行法，不差毫末，指日见功。若此内观，一无时日，二无法则。所居深静之室，昼夜端拱，识认阳神，赶逐阴鬼。达磨面壁九年，方超内院；世尊冥心六载，始出凡笼。故于内观，诚为难事。"

**解读：** 这里揭示了"真正内观"与"存想内观"的本质区别。

### 修炼者常见的误区

很多人：
- 急于求成，想快速超脱
- 强行"多入少出"练胎息（闭气不呼）
- 冥心闭目以为这就是内观
- 结果只是在定境中出了一个**阴神**（尚未化阴为阳的精神体）
- 这种阴神只能成为"清灵之鬼"，绝非纯阳之仙

**阴神与阳神的区别**：阴神是尚未经过炼化的神识，带着阴质；阳神是经过还丹炼形、朝元炼气后形成的纯阳法身。内观的最终目的是"识认阳神，赶逐阴鬼"——认出并培养阳神，驱逐阴质。

### 真正内观的特点

钟离权明确指出：前面的存想内观各有其法、各有其时。但真正的内观：
- **一无时日**：没有固定的时间
- **二无法则**：没有固定的方法

需要"昼夜端拱"，在深静的密室中长期用功。

然后他举了两个极其重要的例子：
- **达摩面壁九年**：才超越内院
- **世尊（佛陀）冥心六载**：才出凡笼

这不是说道教修行要学佛教，而是说真正内观的艰难程度，佛法道法在此是一致的。

> 钟曰："始也自上而下，紫河车搬入天宫。天宫富贵，孰不钦羡？或往或来，繁华奢侈，人所不得见者，悉皆有之。奉道之士，平日清静而守于潇洒，寂寞既已久矣，功到数足，辄受快乐。楼台珠翠，女乐笙簧，珍馐异馔，异草奇花，景物风光，触目如昼。彼人不悟，将谓实到天宫。不知自身内院，认作真境。因循而不出入，乃曰困在昏衢，而留形住世，不得脱质以为神仙。未到天宫，方在内观。阴鬼外魔，因意生像，因像生境，以为魔军。奉道之人，因而狂荡而入于邪中。或而失身于外道，终不能成仙。或以三尸七魄，唯愿人死而自身快乐。九虫六贼，苦于人安，则存留无处。"

**解读：** 这是全书最重要的警告之一。

### 内观中的幻境陷阱

当修炼到一定程度时，内观中会出现极为美好的景象：
- 楼台珠翠
- 女乐笙簧
- 珍馐异馔
- 异草奇花
- 触目如昼

这些景象极其逼真、极其美好。修炼者由于平日清静寂寞已久，一旦见到这些，很容易产生贪恋之心。

### 致命错误

"彼人不悟，将谓实到天宫。不知自身内院，认作真境"——错把内观中的景象当成了真实的天宫。

后果是："因循而不出入"——沉溺在这些景象中出不来，困在"昏衢"（迷途），虽然留形住世，却不能脱质升仙。

### 魔境的根源

"阴鬼外魔，因意生像，因像生境，以为魔军"——内观中的美好景象和恐怖景象，本质上都是"因意生像、因像生境"。是由于修炼者内心的欲望和恐惧投射出来的幻境。

如果被这些幻境所迷惑：
- 或狂荡入于邪中
- 或失身于外道
- 终不能成仙

此外，人体内的"三尸七魄"（道教认为体内有不希望人成仙的存在）和"九虫六贼"（各种内在的障碍因素），也会利用内观中的幻境来干扰修炼者，使人无法超脱。

**通俗理解**：内观中的景象就像一面镜子，反映的是修炼者内心的欲望和恐惧。如果执着于镜中的景象，就永远走不出去。真正的内观是超越所有景象的。"内观"不同于"存想"，前者是纯然观照而不生执着，后者是主动构建意象以引导修炼——两者不可混淆。
